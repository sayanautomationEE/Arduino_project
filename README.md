# Arduino Smart Home Automation

## Project Overview
This project demonstrates a smart home automation
system using Arduino UNO.

## Objectives
- Control home appliances electronically.
- Automate switching operations.
- Demonstrate embedded system applications.

## Components Required
- Arduino UNO
- Relay Module
- Bluetooth Module HC-05
- Jumper Wires
- LEDs
- Power Supply

## Software Used
- Arduino IDE
- Embedded C/C++

## Working Principle
Arduino receives control signals and operates
the connected relay module to control appliances.
